# API Overview

All API endpoints are prefixed with `/api`.

The API uses JSON and returns a `success` boolean together with a human-readable `message` for errors.

## Authentication

| Method | Endpoint | Auth |
|---|---|---|
| POST | `/auth/register` | No |
| POST | `/auth/login` | No |
| GET | `/auth/me` | Yes |
| POST | `/auth/forgot-password` | No |
| POST | `/auth/reset-password` | No |

Password reset uses a time-limited reset token.

## Users / Profile

| Method | Endpoint | Auth |
|---|---|---|
| GET | `/users` | Yes |
| GET | `/users/:id` | Yes |
| PUT | `/users/:id` | Yes |
| GET/POST | `/users/me/goals` | Yes |
| PUT/DELETE | `/users/me/goals/:goalId` | Yes |

Profile functionality includes skills, availability, learning goals, achievements and related user information.

## Messages

| Method | Endpoint | Auth |
|---|---|---|
| GET | `/messages/with/:userId` | Yes |
| POST | `/messages` | Yes |
| PUT | `/messages/with/:userId/read` | Yes |
| GET | `/messages/unread-count` | Yes |

Real-time message delivery is handled through Socket.IO in addition to the REST API.

## Credits

The credits API manages skill-credit balance and transaction history.

## Reports

The reports API handles community reporting and moderation-related data.

## Analytics

The analytics API provides learning/session statistics for the analytics page.

## Admin

Admin routes provide authorized moderation and administrative operations.

## Contact

| Method | Endpoint | Auth |
|---|---|---|
| POST | `/contact` | No |

The contact endpoint validates the submitted name, email, subject and message and stores the contact message.

## Health

| Method | Endpoint | Auth |
|---|---|---|
| GET | `/health` | No |

Used to confirm that the Nexora API is running.

## API Architecture

```text
Frontend
   ↓
fetch()
   ↓
Express API
   ↓
Authentication / Authorization
   ↓
Route Handler
   ↓
Mongoose Model
   ↓
MongoDB
```
